# Automated-Financial-Data-Ingestion-Reconciliation-VBA-Reporting-Tool
This project is a comprehensive Python, Excel VBA, SQL, and Tableau solution designed to fully automate the end-to-end process of financial data ingestion, reconciliation, and reporting. It streamlines the handling of multi-source financial data by combining robust Python scripts for data extraction and transformation with SQL database extracts, eliminating the need for repetitive manual work. The system is built to support recurring daily and weekly cycles, ensuring consistent, accurate, and timely data delivery for downstream processes.

At its core, the solution features modular Excel VBA macros that automate formatting, dashboard refreshes, and report generation, significantly improving process efficiency. A dedicated reconciliation engine performs automated cross-source validation, flagging discrepancies such as balance mismatches, data-type violations, and missing records before they impact ratings or risk calculations. This proactive discrepancy detection helps maintain data integrity and reduces the risk of errors in critical financial workflows.

The platform also delivers dynamic, analyst-ready visualizations through both Excel dashboards and Tableau workbooks. These dashboards provide clear insights into key performance indicators, risk-weighted asset distributions, and portfolio credit migration matrices, enabling quantitative analysts to quickly assess risk and credit exposures. Together, these components create a scalable, production-style automation tool that enhances accuracy, transparency, and decision-making across financial operations.
