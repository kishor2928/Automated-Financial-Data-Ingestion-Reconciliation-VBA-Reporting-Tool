# Tableau Workbooks & Data Sources

This folder contains **Tableau-ready CSV extracts** generated by the Python pipeline.  
You can connect Tableau Desktop / Tableau Public directly to these files to build the dashboards described below.

> **Note:** Native `.twbx` / `.twb` files must be created inside Tableau Desktop.  
> The CSVs below give you everything needed to recreate the recommended views in minutes.

---

## Available Data Sources

| File | Description | Recommended Use |
|------|-------------|-----------------|
| `positions_reconciled.csv` | Full position-level data with recon status & breaks | Exception explorer, detail tables |
| `reconciliation_breaks.csv` | Only the exception / break records | Break analysis dashboard |
| `rwa_distribution.csv` | RWA aggregated by Rating + Product | RWA distribution charts |
| `kpi_summary.csv` | High-level KPI metrics | KPI Scorecard |
| `portfolio_by_rating.csv` | Portfolio composition by rating grade | Portfolio composition views |

---

## Recommended Dashboards to Build

### 1. KPI Scorecard
- Connect to `kpi_summary.csv`
- Create big number cards for: Total Positions, Match Rate, Breaks, Total Market Value
- Use colour thresholds (green ≥ 95% match rate, amber 85–95%, red < 85%)

### 2. RWA Distribution
- Connect to `rwa_distribution.csv`
- Stacked bar or treemap: `total_rwa` by `rating` and `product`
- Add filters for product

### 3. Exception / Breaks Explorer
- Connect to `reconciliation_breaks.csv` or `positions_reconciled.csv`
- Table with filters on `recon_status` and `break_severity`
- Colour code severity (Critical = red, High = orange, Medium = yellow)

### 4. Portfolio by Rating
- Connect to `portfolio_by_rating.csv`
- Horizontal bar chart of notional / market value by rating
- Optional: dual-axis with position count

### 5. Credit Migration Matrix (Advanced)
- Requires two period snapshots
- Use Tableau’s “Pivot” or a calculated field after unioning current + prior extracts

---

## How to Connect in Tableau

1. Open **Tableau Desktop** or **Tableau Public**
2. Connect → **Text file** → select any of the CSVs above
3. Build the views
4. (Optional) Save as `.twbx` and place the file in this folder for version control

---

## Tips for a Clean Portfolio Demo

- Publish the workbook to Tableau Public and link it in the main README
- Keep field names stable so refreshes after new pipeline runs remain reliable
- For production, prefer a database extract or Tableau Server published data source instead of CSVs
